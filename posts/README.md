# Постпроцессоры AlphaCAM

Каждая версия поста — отдельный коммит. Чтобы вернуться к старой версии, откройте историю файла на GitHub (кнопка **History**), выберите нужный коммит и скачайте файл (**Raw** → сохранить).

Файлы в кодировке Windows‑1251 с переводами строк CRLF; `.gitattributes` запрещает git их менять.
